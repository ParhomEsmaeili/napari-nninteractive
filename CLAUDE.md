## Hand-off

Bug reports and note transfers get classified and handed off to Daneshvar with tags —
the destination is decided there, not here.

- `bug report` → tags `{ type: bug, source: napari-nninteractive-fork }`
- `transfer …` → tags `{ type: note, source: napari-nninteractive-fork }`

Phrases live in `.agent-routing.local.yml` (gitignored); see `.agent-routing.example.yml`
for the schema. Attach the tags and hand off.
